# CloudFileFlow Learning Path

- [ ] Python typing, context managers, iterators, and exception handling.
- [ ] FastAPI dependencies, multipart streaming, and response streaming.
- [ ] SQLAlchemy sessions, constraints, transactions, and SQLite limitations.
- [ ] Alembic revision graphs, upgrade/downgrade, drift checks, and startup policy.
- [ ] JWT issuer/expiry/algorithm validation and IDOR prevention.
- [ ] Path traversal, content spoofing, archive bombs, and quarantine design.
- [ ] SHA-256 integrity versus malware detection.
- [ ] Idempotency keys and duplicate event handling.
- [ ] Durable claims, visibility timeout, retry backoff, and dead-letter queues.
- [ ] Storage/database compensation and reconciliation.
- [ ] S3 object security, SQS semantics, IAM, KMS, and LocalStack limits.
- [ ] Structured logs, metrics cardinality, health, and operational dashboards.
- [ ] Unit, API, worker, adapter, and end-to-end testing.
- [ ] Explain the system in two and five minutes without overstating AWS use.
